🔑 Steam Web API Key

Necessária para consultar as horas jogadas na Steam. Obtenha sua key gratuita em steamcommunity.com/dev/apikey

📋 Como obter a API Key

  1. Acesse steamcommunity.com/dev/apikey
  2. Faça login com sua conta Steam
  3. Em "Domain Name", coloque qualquer nome (ex: gcextension)
  4. Clique em "Register" para gerar sua key
  5. Copie a key gerada e cole no campo acima

⚙️ Preferências

Extensão ativa Habilitar/desabilitar os badges no lobby
TTL do cache de horas Tempo para revalidar horas jogadas (em minutos)
Limite CLT (Horas diárias) Limite de horas jogadas por dia nos últimos 14 dias

📊 Faixas de Nível × Horas

Configure as horas mínimas esperadas para cada nível da GamersClub. Esses valores são usados para classificar a compatibilidade entre nível e tempo de jogo.

🔴 Abaixo do mín. + KDR/Steam suspeito = Smurf 🟡 Abaixo do mín. = Possível Smurf 🟢 Acima do mín. = Limpo
